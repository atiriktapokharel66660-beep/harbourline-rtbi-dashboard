# CR-003: Store Manager mobile layout

**Change request:** CR-003 (approved by the project manager; minor change, $3,800, no milestone impact)

## Layout (Power BI mobile, portrait)

1. Header card: net sales today vs target (KPI 10) with a traffic-light indicator
2. Stock alerts: top-500 products below reorder point (KPI 17), tap to see detail
3. Transactions and average transaction value (KPIs 7 and 8)
4. Hourly net sales line chart for today vs the same day last year

## Acceptance

- Loads in 3 seconds or less on a 4G connection
- Shows only the manager's own store (row-level security)
- Tested by two pilot-store managers during UAT
